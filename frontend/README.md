# TODOLIST – Frontend (React + Vite)

## Como rodar
1. Ligue o MySQL e rode o `backend/schema.sql` nele.
2. Backend: `cd backend && npm install && npm run dev` (porta 3333).
3. Frontend: `cd frontend && npm install && npm run dev`
4. Abra http://localhost:5173

A URL da API fica em `.env` (`VITE_API_URL`, `VITE_TASKS_PATH`).
